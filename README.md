How to use this checklist
This checklist is saved as a markdown file. Markdown is a simple text format that works well on GitHub, but you can also turn it into a printable document or use it directly on your computer. Here are a few easy options.

Option 1: Print directly from your browser
Open the file on GitHub.

Click the three dots in the top right corner of the file viewer.

Choose “Print”.

Your browser will open a print preview. You can print it or save it as a PDF.

This is the fastest way to get a printable version.

Option 2: Download the raw file
Open the file on GitHub.

Click “Raw”.

Right click and choose “Save As”.

Save the file to your computer.

You can open the file in any text editor. If you want to print it, open it in a program like Notepad, TextEdit, or VS Code and print from there.

Option 3: Convert it to a PDF using an online tool
If you want a cleaner PDF layout, you can use a free online markdown to PDF converter.

Download the raw file.

Go to any markdown to PDF converter site.

Upload the file.

Download the PDF.

Option 4: Use it directly as a digital checklist
You can keep the file as markdown and use it digitally.

Open the file in a text editor.

Check off items by replacing [ ] with [x].

Add notes or dates anywhere you want.

Markdown works well for digital tracking because it stays simple and readable.

You can print it, save it as a PDF, or use it digitally. Choose whichever method fits your workflow.
